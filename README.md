# Badminton doubles — movement trainer / Парный бадминтон — тренажёр перемещений

Open: https://rommil1990.github.io/badminton-doubles/

A browser app that shows how a doubles pair should move on court against different shots: drag one player and watch the partner take the best spot, play shots with animated flight and footwork, step-by-step lessons and a positioning quiz. Russian, English and Indonesian.

Приложение в браузере: как паре двигаться по корту при разных ударах соперника. Тяните игрока — партнёр сам займёт лучшую точку; удары с анимацией полёта и перебежек, пошаговые уроки и тест. Русский, английский и индонезийский.

Aplikasi di peramban: cara pasangan bergerak di lapangan menghadapi berbagai pukulan lawan. Geser satu pemain — rekannya pindah sendiri ke titik terbaik; pukulan dengan animasi, pelajaran langkah demi langkah, dan kuis.

The whole app is one file: `docs/index.html`. `tools/` holds checks of the positioning model (Node) and the interface (Playwright).
